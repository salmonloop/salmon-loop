## 2024-07-08 - Accessible Navigation Hints
**Learning:** Using purely symbolic text (e.g., `↑↓`, `⏎`) for navigation commands in CLI tools is inaccessible because screen readers rely on raw text output and fail to announce these symbols properly.
**Action:** Always use visually concise but screen-reader-friendly text (e.g., 'Up/Down', 'Enter') for navigation hints to ensure accessibility.
