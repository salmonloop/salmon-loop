## 2026-06-15 - Improve screen reader accessibility for Ink keyboard hints
**Learning:** Screen readers in CLI environments rely on raw text output and fail to announce symbols like `↑↓` or `⏎` properly, causing accessibility issues.
**Action:** Use visually concise but screen-reader-friendly text for navigation hints (e.g., 'Up/Down' instead of '↑↓', 'Enter' instead of '⏎').
