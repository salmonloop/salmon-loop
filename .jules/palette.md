## 2024-10-24 - Screen Reader Friendly Keyboard Navigation Symbols
**Learning:** For command-line selection interfaces or overlays using Ink, purely symbolic text (like `↑↓` or `⏎`) is not announced properly by screen readers, causing accessibility regressions.
**Action:** Replace symbolic navigation text with visually concise but screen-reader-friendly text like "Up/Down", "Enter", and "Esc".
