## 2024-07-16 - Screen Reader Friendly Navigation Hints
**Learning:** For complex command-line selection interfaces or overlays using Ink, purely symbolic text (e.g., `↑↓`, `⏎`) fails to be announced properly by screen readers in CLI environments, causing an accessibility regression.
**Action:** Use visually concise but screen-reader-friendly text (like 'Up/Down', 'Enter') instead of symbols to ensure proper accessibility in CLI navigation hints.
