## 2024-07-12 - Screen Reader Compatibility for CLI Microcopy
**Learning:** Screen readers in CLI environments fail to announce purely symbolic text like `↑↓` or `⏎` properly, causing an accessibility regression in keyboard navigation hints.
**Action:** Always use visually concise but screen-reader-friendly descriptive text (e.g., 'Up/Down', 'Enter', 'Esc') instead of raw symbols.
