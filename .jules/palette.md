## YYYY-MM-DD - [CLI Navigation Accessibility]
**Learning:** [For complex command-line selection interfaces using Ink, purely symbolic text for navigation hints (e.g., `↑↓`, `⏎`) fails to be announced properly by screen readers in CLI environments. Screen readers rely on raw text output and these symbols cause accessibility regressions.]
**Action:** [Use visually concise but screen-reader-friendly text like 'Up/Down' and 'Enter' instead of symbols for keyboard navigation hints.]
