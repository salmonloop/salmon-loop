## 2024-05-18 - Screen Reader Accessibility in CLI UI
**Learning:** For complex command-line selection interfaces or overlays using Ink, replacing descriptive navigation words (like 'Up/Down', 'Enter') with purely symbolic text (e.g., `↑↓`, `⏎`) causes screen readers in CLI environments to fail to announce these symbols properly, causing an accessibility regression.
**Action:** Use visually concise but screen-reader-friendly text (e.g., 'Up/Down' instead of '↑↓') in terminal UI microcopy.
