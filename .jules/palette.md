## 2024-07-14 - Screen-Reader Friendly CLI Navigation Microcopy
**Learning:** Screen readers in CLI environments rely on raw text output and fail to announce purely symbolic text (e.g., ↑↓, ⏎) properly for navigation hints, causing an accessibility regression.
**Action:** Use visually concise but screen-reader-friendly text (like 'Up/Down', 'Enter') instead of symbols for keyboard navigation instructions in CLI UI components.
